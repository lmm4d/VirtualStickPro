# VirtualStickPro
适用与边界 适合：单机游戏、模拟器、Galgame、老游戏，以及任何需要在触屏上补一套虚拟按键的场景。  不适合：带内核级反作弊的游戏（ACE / EAC / GameGuard）。这类反作弊会检测输入模拟， 轻则输入被忽略，重则封号——这跟软件干不干净无关，任何按键模拟都一样。 那种情况请用手柄（系统标准输入通道）或官方云版。  已知限制：单显示器未测多屏坐标换算；只能发键盘事件，不能发鼠标移动/点击； 触摸需设备支持 Windows 触摸消息。
项目简介
一条鱼写的 Windows 触屏虚拟摇杆。 空白区域穿透、不抢焦点、多指同时可用、无毒无钩子。
是一个给 Windows 平板 / 触屏笔记本用的屏幕虚拟摇杆 + 自定义按键工具： 把触屏上的推摇杆、点按钮，翻译成游戏能识别的键盘按键。它浮在游戏画面之上， 但只在有控件的地方挡触摸，其余像素完全穿透，也不把游戏切到后台。
